# 少女前线2：追放 模型库（girl_frontline5）

本仓库是 [Carlutic/model-viewer](https://github.com/Carlutic/model-viewer) 少女前线分类的原始清晰度模型库之一。
由于单个 GitHub Pages 站点上限 1 GB，这一批模型被拆分为 girl_frontline2..5 四个仓库，查看器会把它们合并显示。

## 说明

- **模型文件保持原样**：PMX 与贴图均为作者原始文件，逐字节复制，未缩放、未转码、未改色深。
- 查看器只读取 `girl_frontline.json` / `skins.json`，并按 `chars/<角色>/` 结构加载模型。
- `Covers/` 中是查看器用的 512px 缩略图（界面素材，不是模型贴图）。
